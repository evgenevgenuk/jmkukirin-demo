# JMkukirin — демо

Статична демо-версія інтернет-магазину запчастин для електросамокатів.

Тут можна походити по сайту як покупець: вибрати модель самоката, подивитися каталог і товари, покласти щось у кошик і пройти оформлення. Місто й відділення Нової Пошти підтягуються зі справжнього довідника.

Оплата, вхід, кабінет, Telegram-боти й адмінка працюють лише на повній версії з сервером, тут замовлення не створюються.
